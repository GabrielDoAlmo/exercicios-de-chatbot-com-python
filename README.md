## 🌟 Sobre o Projeto

Este projeto compila 30 desafios práticos de desenvolvimento de chatbots resolvidos em Python utilizando o **Google Colab** (Jupyter Notebooks). O objetivo é demonstrar a evolução na construção de agentes conversacionais, começando com respostas engessadas e evoluindo para sistemas dinâmicos que interpretam intenções e processam linguagem humana.

---

## 📂 Estrutura dos Módulos

Os exercícios estão divididos em três listas principais, organizadas de forma crescente de complexidade:

### 📁 Lista 01: Estruturas de Decisão
Foco nos fundamentos da lógica de programação para chatbots.
* **Técnicas utilizadas:** Controle de fluxo (`if/elif/else`), manipulação de *strings* (`lower()`, `in`), lógica booleana e validação de *inputs*.
* **Aplicações:** Chatbots de suporte técnico básico, triagem médica, controle de horário comercial e sistemas de saudação.

### 📁 Lista 02: Chatbots Baseados em Regras
Foco em arquiteturas conversacionais estruturadas e controle de estado.
* **Técnicas utilizadas:** Funções personalizadas, dicionários de intenções, **Expressões Regulares (`re.search`)** e laços de repetição (`while`).
* **Aplicações:** Menus interativos, fluxos de múltiplas etapas, personalização com o nome do usuário e controle de acesso (Admin vs. Usuário).

### 📁 Lista 03: Processamento de Linguagem Natural (PLN)
Foco em tornar o bot capaz de compreender e tratar a linguagem humana de forma flexível.
* **Técnicas utilizadas:** Tokenização (`split()`), normalização e limpeza de texto, remoção de pontuação e cálculos de frequência de palavras.
* **Aplicações:** Pré-processadores de texto, identificadores de palavras-chave otimizados e extratores de contexto.
